# 在线部署（让公网地址也能上传图片）

GitHub Pages 只能放静态文件，跑不了 Python，所以 **Pages 版永远不能上传图片**。
要让公网地址和 `http://127.0.0.1:8899/` 完全一样，必须把后端放到一台有公网的机器上。

仓库里已经放好 `render.yaml`，用 Render 的免费档最省事（不用 Docker，不用命令行）。

## 一、在 Render 上部署（约 10 分钟，一次性）

**最快路径（一键）**：直接打开这个链接，仓库和配置会自动带好：

<https://render.com/deploy?repo=https://github.com/lulu520-1314/trust-shield>

用 GitHub 授权登录 → 点 **Apply** → 等 3–6 分钟。

手动路径（如果上面的链接打不开）：

1. 打开 <https://dashboard.render.com/register>，用 GitHub 账号登录（免费，不用信用卡）
2. 点 **New +** → 选 **Blueprint**
3. 选仓库 `lulu520-1314/trust-shield` → **Connect**
4. 它会自动读到 `render.yaml`，直接点 **Apply**
5. 等 3–6 分钟构建，完成后的地址形如
   `https://trust-shield-xxxx.onrender.com`

打开这个地址，**和本地一模一样**：能上传图片、能导入文档、能自由提问。

## 二、免费档的两个限制（提前知道，别踩坑）

| 限制 | 表现 | 应对 |
|---|---|---|
| **闲置 15 分钟后休眠** | 第一次打开要等 30–60 秒冷启动 | 演示前先自己打开一次「唤醒」 |
| **每月 750 小时** | 单个服务刚好够跑满一个月 | 只开一个服务 |

内存 512 MB 够用：实测一次完整分析后进程只占 **84 MB**。

## 三、如果 Blueprint 报错

常见两种：

- **提示 region 不支持**：把 `render.yaml` 里的 `region: singapore` 这行删掉，重新 Apply。
- **构建失败在 `pip install`**：把 `PYTHON_VERSION` 改成 `3.11.9`（默认值已经写了），
  或确认 `requirements.txt` 里没有需要编译的包。

## 四、两个地址怎么分工

| 地址 | 用途 | 特点 |
|---|---|---|
| `https://lulu520-1314.github.io/trust-shield/` | 给评委**随手点开看** | 秒开、不用等；但只读 |
| `https://trust-shield-xxxx.onrender.com` | 给评委**真上手试** | 全功能；冷启动慢 |

两个地址建议都写进 README 和 PPT。

## 五、更新线上版本

Render 连着 GitHub，**推送到 main 就会自动重新部署**（约 2–3 分钟）。
静态版需要额外跑 `python scripts/build_demo.py` 再推，具体见 README 的「更新网站」一节。
